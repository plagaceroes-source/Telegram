Как считается оценка и флаги

Зачтено — вступившие, которые не ушли в первые {{ report.rules.retention_days }} дн. По ним строится рейтинг. Оценка 0–100 складывается из удержания (50%), быстрых уходов за 24 ч (15%), профиля аккаунтов (20%) и всплесков (15%); если данных на какую-то часть не хватает, её вес перераспределяется. Оценка появляется от {{ report.rules.min_sample }} вступлений.

Всплеск — {{ report.rules.spike_min_joins }}+ вступлений за {{ report.rules.spike_window_min }} мин, если это ≥ {{ (report.rules.spike_day_share * 100) | round | int }}% вступлений блогера за день. Сам по себе всплеск ещё не накрутка (удачный пост тоже его даёт) — смотрите, что с этими людьми дальше.

Профиль — доля «свежих» аккаунтов (по номеру id), без username и с нетипичным языком сравниваются с нормой; отклонение от {{ (report.rules.profile_deviation * 100) | round | int }} п.п. даёт флаг. Данные профиля собираются только с момента включения, по старым вступлениям их нет.

Флаги: один — «Проверить», два и больше — «Подозрительно». Накрутку живыми людьми за вознаграждение отличить нельзя: против неё помогает именно правило «зачтено, если остался N дней». Пороги меняются переменными BLOGGER_* на сервисе admin.
