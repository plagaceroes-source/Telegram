## Решения клиента (раздел 9 ТЗ)
| Вопрос | Ответ | Влияние |
|---|---|---|
| Языки | Старт только RU, EN через 1–2 месяца | i18n заложен, включён только `ru` |
| Версии | Один сайт с переключателем языка | папки `/ru`, `/en` |
| Каталог | Старт — витрина, потом расширение | MVP без фильтров/поиска |
| Цены | Только «рассчитать стоимость» | цен нет нигде |
| Квиз | Не в первом релизе | фаза 2 |

| Брендбук | Нет, ориентир — instagram.com/soverion.merch | палитра/шрифты временные |
| Тексты/фото | Тексты и переводы — мы; мокапы — клиент | нужна база мокапов |
| Испания, юрлицо ЕС | Позже | без EU-блоков, GDPR-баннер на этапе EN |

2. Разобрать стиль Instagram → UI-кит, заменить временную палитру
3. Страницы услуг, производство, о нас, кейсы (минимум), юридические
4. Баннер cookie, GA4 + Яндекс.Метрика, цели
